## Later parity-state revision: independent mathematical addendum

The proposed one/two-state compression is sound. With integral local outputs k_i and residuals f_i=y_i-k_i, total-minus-lines is R_0(K+F)-K. Outer FLOOR/CEILING reduce to floor(F)/ceil(F), requiring only one state. HALF_EVEN reduces to HE(F+kappa)-kappa for kappa=K mod2; these maps are monotone, so attained error endpoints for each parity suffice. Independence permits every selected local endpoint to combine and reconstruct a feasible witness. Two common HALF_EVEN lines, y_1=1/2 and y_2 in {0,1}, give the same F=1/2 but discrepancies zero and one, so retaining parity is necessary in general.

Nonnegative HALF_UP/DOWN/UP use the extended terminal functions floor(F+1/2), floor(F), and ceil(F), even if F is negative. Applying signed rounding directly to F is unsound. Unequal output quanta, nonintegral unrounded locals, coupled domains and arbitrary signed sign-sensitive totals remain outside this guarantee.

A simpler equivalent aggregation independently reinforces that the combinatorial mechanism is elementary: choose each line's best parity endpoint; to obtain opposite total parity, change one flexible line with the smallest loss (or increase for minima). Any odd number of changes has nonnegative aggregate cost at least that cheapest single change. Zero-cost changes and unreachable opposite parity are handled explicitly. This achieves the same O(n) combination and witness cost as the two-state recurrence.

The sharp enumerative bound is O(sum_i min(T_i,width_i)+n), T_i=den(a_i/2). A denominator-indexed residue state space is unnecessary; offsets do not enlarge T_i. Exact Fraction sums can still have growing denominator bit lengths. The arithmetic-operation convention excludes rational bit costs. Individual periods may be exponentially large in binary encoding, but this is an implementation bound rather than an inherent complexity lower bound. At fixed local parity b, putting k=2t+b gives a two-variable integer optimization in x,t over a rational rounding strip. Strict endpoints integerize; Lenstra's fixed-dimension theorem gives a polynomial-bit theoretical route to local extrema. This inference does not mean the prototype implements that route. See [parity_revision_audit.md](../literature/parity_revision_audit.md) for explicit strips and counterexamples.
